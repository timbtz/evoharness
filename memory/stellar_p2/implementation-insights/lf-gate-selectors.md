# LF Finalist Gate Selection Keys
The low-fidelity (LF) finalist gate selects the boundary to return. It MUST evaluate using the harness-accurate novelty-aware key (`fm.score - 0.05 * max(0, 1 - bank_dist/1e-3)`) rather than raw `fm.score()`, which is blind to the penalty. The return gate must also strictly verify `bank_dist` against the 1e-3 floor.

## How it was tried
- `stellar_p2-s101-20239089` c0002: The LF gate selected by raw `fm.score`, silently returning an in-ball camper (`bank_dist = 0.000214`) that collapsed to val -0.0125.
- `stellar_p2-s101-20239089` c0005r1: Repeated the raw score bug, returning a boundary at `bank_dist = 0.000188` and dropping to val -0.0153.
- `stellar_p2-s101-20239089` c0003f: Attempted to move QI-margin pressure into the LF gate return selector with hard bounds (`QI_RET = -4.0`). The constraint proved unreachable for escaped boundaries; the fallback logic collapsed, yielding a catastrophic val of -0.8499.
- `stellar_p2-s101-20239089` c0018r1 (val -0.5475): a 3-way escape triage seeded a sigma~3e-3 random walk that pushed through the QI wall (log10_qi -3.933); the LF gate returned that UNVERIFIED infeasible boundary. c0018f hardened the gate (never return a boundary that failed LF verification) and tied the plateau safely.
- `stellar_p2-s101-20239089` c0007f, c0008f, c0010f: Surgically fixed the LF gate to select by the novelty/margin-aware `_key` on LF metrics, safely avoiding the vlf-blindness landmines. Repeatedly added lexicographic QI-margin tiebreaks (`TIE_L` and `QI_TIE_L` bands) to trade small amounts of L for QI margin. **Outcome:** Tiebreaks proved inert because the vlf-blindness death spiral meant the finalist pool only ever contained one dominant entry (the Phase-0 escape). There were never two near-tied entries to break a tie between.
- `stellar_p2-s102-48117936` c0002, c0002f: Attempted to return escaped boundaries, but the LF gate certified safety only via generic `feasibility <= SAFE_RET`. Because it lacked a specific `log10_qi <= -4.0` check, it returned a wall-camping escape (log10_qi -3.988) that collapsed to val -0.28.
- `stellar_p2-s102-48117936` c0003: Tried gating the return path on `best_s > 0`. When the raw escape broke physics (train -0.16), the gate skipped ALL safety checks and returned the catastrophic boundary (val -0.28).
- `stellar_p2-s102-48117936` c0013, c0013f: c0013 added an aspect-relief micro-contraction (`_dilate(-1.6e-3)`) but the return gate leaked, returning the contracted in-ball boundary (`bank_dist 0.000463`). c0013f patched the leak by tracking `out_b` (highest-key boundary that is feasible AND `bank_dist >= NOV_MIN`) and preferring it at return. Outcome: the fix never bit — no feasible out-of-ball candidate existed in the pool, so the return stayed bd 4.63e-4, bit-identical to c0003f. The leak diagnosis was correct, but the binding failure is escape SUPPLY, not gate selection.

## Why it worked / failed
Raw `fm.score()` will always favor the unpenalized in-ball anchor over an escaped boundary, effectively undoing the structural escape during the final selection step. Pushing QI bounds into the return gate (c0003f) fails because the LF gate has a tiny pool of candidates and cannot reliably find a survivor if the bounds are tight. Lexicographic tiebreaks are structurally sound but strictly require a polish loop that actually generates diverse LF finalists. `best_s > 0` guards silently bypass all verification when an escape lands deeply infeasible. Aspect contractions drag the boundary back into the ball and must be heavily filtered.

## Verdict
recurring pitfall — Always evaluate LF finalists using the exact harness acceptance key so novelty is penalized. Do not invent hard constraint gates inside the return selector unless paired with a robust raw-score fallback. For lexicographic tiebreaks to fire, the polish loop MUST escape the deterministic plateau first. Never gate safety checks on `best_s > 0`. Explicitly filter for `bank_dist >= 1e-3` on all return paths.
